How it works

Every receipt import goes through a confirmation step before it becomes a watched return. The app is built to be useful without account setup.

01 Input

Capture

Paste receipt text, choose a receipt photo, forward an order email, or share receipt text into the app.

02 Review

03 Act

Track proof, policy notes, packaging, drop-off decisions, and status from a dedicated Return Prep checklist.

Privacy Policy

Last updated June 5, 2026. This policy covers the Return To iOS app, hosted review API, email forwarding flow, and this website.

No ad tracking No sale of personal data User-selected receipts only

What Return To collects

  • Receipt and order details you choose to import, such as merchant, item, amount, purchase date, order number, return deadline, notes, and proof text.
  • Email receipt content you choose to paste, share, or forward to Return To.
  • User-selected receipt images for on-device text recognition.
  • App settings such as backend URL override and private forwarding token.

How data is used

  • To parse receipts and order confirmations.
  • To calculate likely return deadlines and schedule reminders.
  • To show return prep checklists, notes, and status.
  • To route forwarded receipts to the correct app install.

Storage and sharing

  • Return data is stored locally in the app and may sync through the hosted review API when configured.
  • Forwarded receipts are processed by Cloudflare Email Routing and the Return To API to create review candidates.
  • Return To does not sell personal data and does not use data for third-party advertising or tracking.
  • Return To does not currently have account login or identity-linked profiles.

Your choices

  • You can delete return cards from the app.
  • You can stop forwarding receipts at any time.
  • You can reset demo data from Settings.
  • You can contact support for privacy questions or deletion requests related to hosted review data.
