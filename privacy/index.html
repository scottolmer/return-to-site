Privacy Policy

This policy covers the Return To iOS app, hosted review API, email forwarding flow, and this website.

Information Return To Collects

Return To collects receipt and order details you choose to import, including merchant, item, amount, purchase date, order number, return deadline, notes, proof text, and related email receipt content. The app may also process receipt images you select for on-device text recognition.

The app stores settings such as a backend URL override and a private forwarding token. The website does not use analytics or advertising trackers.

How Information Is Used

Return To uses imported receipt information to parse purchase details, calculate likely return deadlines, schedule reminders, maintain return prep checklists, and route forwarded receipts to the correct app install.

Storage, Sharing, and Tracking

Return data is stored locally in the app and may sync through the hosted review API when configured. Forwarded receipts are processed by Cloudflare Email Routing and the Return To API to create review candidates. Return To does not sell personal data and does not use data for third-party advertising or tracking.

Your Choices

You can delete return cards from the app, stop forwarding receipts at any time, and contact support for privacy questions or deletion requests related to hosted review data.
